# Project ZenScreen

Your mindful companion for digital balance and focus. A mobile-first web application designed to help users track screen time, set healthy limits, and improve digital well-being through AI-powered coaching.

## Vision
To empower users to take control of their digital lives through awareness, gamification (streaks), and personalized AI guidance.

## Tech Stack
- **Frontend**: HTML5, Vanilla CSS (Premium Aesthetics), Vanilla JavaScript.
- **Backend**: Node.js, Express.
- **Database**: SQLite (sql.js) for lightweight, portable, in-memory with persistence.
- **AI**: Google Gemini 1.5 Flash (via API).
- **Auth**: JWT-based authentication with bcrypt password hashing.

## Core Features
1. **Premium Dashboard**: Real-time screen time tracking and visualization.
2. **Safety & Limits**: App-specific daily limits and a dedicated "Focus Mode" timer.
3. **AI Coach**: Personalized insights and a conversational coach for behavioral change.
4. **Data Persistence**: Full user accounts, progress syncing, and historical data storage.
5. **Mobile-First Design**: Optimized for Android/iOS with a premium, dark-mode aesthetic.
